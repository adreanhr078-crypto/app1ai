## تدقيق الصور الثلاث

- الصور الثلاث ليست لنفس الوجه أو نفس نسب الجسد، لذلك لا تصلح كأساس هوية ثابتة أو IPAdapter reference موحد.
- الصورة الثانية أفضلها في التعبير العام والوضعية، لكنها صفحة مولدة ذات كتابة وعناصر غير موثقة؛ تبقى **مرشح مزاج** فقط.
- لا توجد مساقط أمام/جانب/خلف متعامدة، ولا A-pose، ولا قياسات، ولا اختبار deform، ولا علامة `EX-011` المباشرة على الجلد.
- النتيجة: **REJECTED FOR CHARACTER LOCK** و**ACCEPTED AS NON-CANON MOOD EXPLORATION**.

## تدقيق خط ComfyUI الذي شغله Antigravity

تم إيقاف العملية الخلفية بعد الفحص لأنها لا تحقق ما ادعته:

- `run_echo_generation.py` يبني دالة workflow وقائمة سبعة prompts، لكنه لا يستدعي الدالة ولا يرسل أي POST إلى ComfyUI؛ لذلك لا يمكنه وضع أي صورة في الطابور.
- سكربت PowerShell يعتبر وجود الملف نجاحاً بلا فحص الحجم أو SHA-256، ويستعمل Python عامّاً بدلاً من runtime محمول مثبت، ولا يحفظ log أو manifest أو seed receipt.
- ملف CLIP Vision تُرك بحجم `0` بايت بعد إيقاف التنزيل؛ لا يجوز تحميله أو اعتباره صالحاً.
- تم التحقق من الملفين المكتملين محلياً ومن مستودعيهما الرسميين:
  - `animagine-xl-3.1.safetensors`: الحجم `6,938,325,776`، SHA-256 `E3C47AEDB06418C6C331443CD89F2B3B3B34B7ED2102A3D4C4408A8D35AAD6B0`، مطابق لمصدر Hugging Face، والرخصة المعلنة `openrail++`.
  - `ip-adapter_sdxl_vit-h.safetensors`: الحجم `698,391,064`، SHA-256 `EBF05D918348AEC7ABB02A5E9ECEF77E0AAEA6914A5C4EA13F50D45EB1681831`، مطابق لمصدر Hugging Face، والرخصة المعلنة `apache-2.0`.
- نجح فحص بنية Safetensors للملفين، لكنه لا يثبت ملاءمة GPU أو جودة الهوية أو صلاحية workflow الكامل.

**الحكم:** نحتفظ بالوزنين الموثقين كمدخلات محتملة، ونرفض السكربتين كأداة إنتاج. لا نبدأ توليداً إنتاجياً حتى تكتمل حزمة الأوزان المرخصة، وتُبنى وصفة API صحيحة قابلة لإعادة التشغيل، وتجتاز صورة smoke واحدة مع log/seed/hash/provenance.

## ما يدخل الخطة المعتمدة

- Canon والمانهوا هما مرجع الشكل والقصة؛ فيديوهات المشروع مرجع حركة وإضاءة فقط؛ صور AI تسد فجوات محددة ولا تنشئ Canon.
- Echo قبل التحول يمكنه القتال والقتل البشري عند ضرورة القصة، من دون أي قدرة Zero. لا نضيف combat إلى G0 لمجرد إثبات هذا القرار؛ يبقى مؤجلاً حتى بوابة القتال.
- نموذج Echo الحالي يمر إجبارياً عبر `VRoid Studio → Blender authored refinement → validated GLB → Godot`.
- نختبر في Echo: الدفء الإنساني، قابلية تصديق الصدمة، استمرارية نفس الوجه نحو Zero، وضوح silhouette، وظهور `EX-011` مباشرة على الجلد.
- كاميرا المانهوا، التباين بين الأمان والخوف، وتسليم التحكم سريعاً عناصر مقبولة داخل Vertical Slice ما دامت قابلة للتخطي وتحترم Reduced Motion.

## ما يبقى مؤجلاً أو مرفوضاً

- أي عقد دم، قوى Zero، تحول، عدو roster، sanity punishment، حذف تلميحات، موت NPC كعقوبة، gacha، عالم مفتوح، أو نظام مدينة.
- أي ادعاء `FINAL/APPROVED/LOCK/CLEARED` صادر عن وكيل من دون دليل Canon وبوابة المالك.
- أي تثبيت لإصدار Godot 4.5 أو Blender 4.2؛ البيئة المتحققة حالياً Godot `4.7.2` وBlender `5.2.1 LTS`.
- استعمال الصور الثلاث أو نموذج Blender الإجرائي السابق كـEcho نهائي. كلاهما proof تقني فقط.
