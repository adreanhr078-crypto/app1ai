# Sector 11 Foundation

This is the bounded Godot production-foundation proof for 11:11. It contains
one small training room, one temporary Echo rig, one third-person camera, three
basic interactions, an authority-safe fixture, and deterministic headless tests.

It is not an open world, combat slice, Canon environment, final Echo model, or
shipped runtime. `EchoVisual_NON_CANON` uses the rejected procedural Blender
placeholder only to prove import and animation wiring while the mandatory VRoid
base is authored.

## Commands

Run from the repository root:

```bash
npm run godot:doctor
npm run godot:foundation:import
npm run godot:foundation:test
npm run godot:foundation:smoke
```

The command wrapper allows only this tracked project. Generated `.godot` data
and logs stay outside the runtime evidence set.

## Scope boundary

- Godot owns local movement, camera, animation presentation, and proximity.
- React/Cloudflare/Firebase remain authoritative for identity, save, receipts,
  progression, inventory, rewards, and Canon exposure.
- The test fixture accepts only `FOUNDATION_TEST_ONLY` and returns no reward or
  progression value.
- The door interaction remains authority-gated.
- Arabic/English prompts are live UI and are never baked into GLB assets.

## Quality gate

Technical PASS requires clean import, scene parsing, input actions, the three
interactions, an idempotent reward-free fixture, an animated validated GLB, and
stable headless smoke. Visual AAA PASS additionally requires the approved VRoid
Echo base, Blender identity pass, runtime capture, and measured desktop/mobile
performance. The technical placeholder cannot satisfy visual AAA acceptance.
