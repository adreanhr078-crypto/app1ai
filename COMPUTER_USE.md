# Universal Computer Use

This project exposes Microsoft Playwright MCP for browser automation.

Supported intended clients:
- OpenAI Codex
- Claude Code
- Cline
- Roo Code
- Continue Agent
- VS Code MCP-aware agents
- Other MCP-compatible clients

Preferred browser tool:
Playwright MCP

Use it for:
- opening browser pages
- clicking
- typing
- scrolling
- forms
- screenshots
- DOM/CSS inspection
- console/network debugging
- browser testing

Prefer semantic accessibility-tree interaction over coordinate clicking.

For passwords, MFA, CAPTCHA, payment confirmation, UAC, or other sensitive
authentication, stop and let the user complete the protected step manually.
